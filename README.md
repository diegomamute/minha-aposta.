# Minha Aposta

Portal informativo de futebol mundial, com interface responsiva em português.

## Estrutura
- `index.html`: estrutura da página
- `style.css`: identidade visual e layout responsivo
- `app.js`: interações do menu, filtros e busca

## Dados esportivos
A interface está preparada para receber uma API de futebol. Para exibir partidas, placares, classificação e odds reais, é necessário contratar/selecionar um provedor que autorize esse uso e configurar a chave de API no backend. Não inserir chaves secretas diretamente no JavaScript público.

**Importante:** esta versão é exclusivamente informativa. Não oferece apostas, depósitos, saques ou pagamentos.

## Publicar com GitHub Pages
No GitHub, abra Settings → Pages, selecione Deploy from a branch, escolha `main` e a pasta `/ (root)`, e salve.
